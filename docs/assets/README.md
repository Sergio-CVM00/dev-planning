### Generation prompt

Use case: illustration-story.
Asset type: static GitHub README hero banner for Dev Planning.
Primary request: "The cartographer's table": an original anime-style adult human thoughtfully planning together with a small luminous non-humanoid agent that draws a branching decision map with a floating quill.
Scene: a wooden cartography desk in a quiet navy-blue study. Large warm parchment covers most of the foreground. Visible routes fork between small island outlines and circular decision markers; one route is confidently connected in warm gold, alternative routes are dotted, a few gently crossed out, and the unexplored outer map fades into mist.
Subject: the human seen in three-quarter view, one hand at their chin and the other near the map, looking engaged and thoughtful. The tiny agent is a restrained cyan-gold glow guiding the quill over an unfinished branch, clearly collaborating with the human.
Style: polished original anime adventure illustration, clean expressive linework, painterly shading, attractive editorial composition, no existing franchise characters.
Composition: wide horizontal banner approximately 2:1, large readable map as the central focal element, human and agent secondary but clearly visible, safe margins for a README crop, not a busy collage.
Lighting: warm amber desk light against deep navy atmosphere, muted parchment and subtle gold route highlights.
Text: none.
Avoid: logos, watermarks, pseudo-writing, illegible labels, text, skulls, treasure chests, swords, generic humanoid robots, clouds as mascots, excessive magical sparkles. The subject is reasoning and mapping options, not coding or performing implementation.
